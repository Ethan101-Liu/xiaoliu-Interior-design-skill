# 室内设计建模与改图工作流

## Overview

本 Skill 把"室内设计"请求从泛泛而谈变成五阶段标准化流程：**需求分析 → 方案策划 → 效果图生成 → 改图迭代 → 建模落地**。AI 按此流程产出可直接使用的设计方案文档、效果图、AI 生图提示词和建模操作指令。

完整流程：

1. 判断任务类型（出图 / 改图 / 建模指令 / 完整方案）
2. 需求分析：收集空间、风格、预算、居住信息
3. 方案策划：输出结构化设计方案
4. 效果图生成：方案转提示词 → 调用生图工具出图
5. 改图迭代：根据反馈做图生图修改
6. 建模落地：输出酷家乐 / SketchUp / 3ds Max / Blender 分步指令
7. 交付与校验：核对需求覆盖度，汇总交付物

## 任务类型判断

先判断用户的核心诉求，再走对应分支：

- **要完整方案或未明确** → 走完整流程（阶段 1 → 2 → 3 → 5，效果图默认生成）
- **要效果图 / 改图**（"出张效果图""把这张图改成奶油风""去掉这个吊灯"）→ 有参考图走阶段 4，无参考图走阶段 3
- **只要建模 / 软件操作指令**（"这个户型在酷家乐怎么建模"）→ 直接走阶段 5，跳过 2-4
- **只问风格 / 搭配建议**（"新中式适合什么颜色"）→ 引用 `references/style-library.md` 直接回答，不走完整流程

## 阶段 1：需求分析

收集以下信息，缺失的按重要性处理：

| 信息 | 说明 | 缺失时处理 |
|---|---|---|
| 空间类型与面积 | 客厅/卧室/厨房/全屋，平米数 | 合理默认（如客厅 25㎡），标注假设 |
| 户型结构 | 承重墙、管线、采光面（有图最好） | 无图时用文字描述布局 |
| 风格偏好 | 奶油风/意式极简/新中式等 | 问用户或推荐 2-3 种供选 |
| 居住人数与成员 | 影响收纳、床位、动线 | 默认家庭常规配置 |
| 预算 | 总预算或单价 | 默认中档，标注假设 |
| 核心诉求 | 储物量、采光、儿童安全、宠物等 | 逐条问清，这是方案差异点 |
| 参考图 | 用户上传的意向图 | 有图必须用图生图方式对齐风格 |

输出一份结构化**需求摘要**：空间、面积、风格、预算、核心诉求、假设项清单。假设项必须显式列出，让用户可纠偏。

## 阶段 2：方案策划

输出设计方案文档，按此模板：

```markdown
# [空间]设计方案（[风格]）
## 1. 风格定位 —— 风格名称 + 一句话理念 + 关键词（引用 style-library.md）
## 2. 空间布局 —— 平面分区描述：动线、功能分区、尺寸要点
## 3. 色彩方案 —— 主色/辅色/点缀色 + 色值建议
## 4. 材质清单 —— 墙面/地面/柜体/软装材质与用量要点
## 5. 灯光设计 —— 主灯/辅助灯/氛围灯布局与色温
## 6. 家具清单 —— 逐件：名称、尺寸、数量、材质、摆放位
## 7. 预算分配 —— 按硬装/软装/家电分项占比
## 8. 待确认项 —— 影响方向的问题留给用户拍板
```

全屋定制场景（衣柜、橱柜、榻榻米、护墙板）必须给出**柜体分项**：功能区划分、柜门材质、五金、尺寸标注。

## 阶段 3：效果图生成

1. 从方案文档提取参数：空间、风格、面积、材质、灯光、氛围
2. 调用 `scripts/build_prompt.py` 组装标准提示词（中英文 + 负面提示词）
3. 用生图工具（image_gen 等）生成效果图，比例按空间用途选择：客厅横图 16:9 / 3:2，全屋效果 4:3，手机端竖版 9:16
4. 提示词细节规范见 `references/prompt-library.md`
5. 交付效果图时同时附上所用提示词，方便用户自行复现或微调

## 阶段 4：改图（图生图修改）

判断修改类型并执行：

- **风格转换**（"改成奶油风"）→ 引用 `references/style-library.md` 的目标风格关键词，图生图重绘
- **局部修改**（"换个茶几""去掉背景墙装饰"）→ 图生图局部编辑，仅描述要改的部分
- **元素替换 / 颜色调整 / 画质增强** → 对应图生图指令，保持原图比例
- **多方案对比**（"再来两个配色方案"）→ 同一构图生成 2-3 张变体供选择

改图指令规范：不重复描述原图已有特征，聚焦改变部分；保持原图比例；一次只改一个维度的优先，多维度修改需用户确认优先级。

## 阶段 5：建模与改图操作指令

按用户目标软件输出分步操作指令：

- **酷家乐** → 读 `references/kujiale.md`，输出：导入户型 → 墙体门窗 → 硬装（吊顶/地面/墙面）→ 家具布置 → 材质替换 → 灯光 → 渲染导出的完整步骤与参数
- **SketchUp / 3ds Max / Blender** → 读 `references/3d-modeling.md`，按软件输出：场景单位与建模流程 → 墙体/门窗/柜体建模 → 材质赋予 → 灯光布置 → 渲染器设置
- **改图类操作**（改墙、改布局、替换模型）→ 给出精确到工具菜单/快捷键的步骤

指令必须可执行：含工具名、菜单路径、快捷键、参数值；不写"大致""差不多"这类模糊表述。

## 交付与校验

交付前按清单核对：

- [ ] 需求摘要中的每条诉求都有对应方案回应（没有的要标注"未覆盖"）
- [ ] 假设项已显式列出，未静默编造
- [ ] 效果图已出（如适用），且附提示词
- [ ] 建模指令含具体菜单/快捷键/参数，可照做
- [ ] 全屋定制方案含柜体分项与尺寸

交付形态：效果图用图片卡片交付；方案文档、操作步骤、提示词随回复给出。用户反馈后进入改图迭代，循环直至确认。

## Resources

### scripts/build_prompt.py
从结构化设计参数生成标准化 AI 生图提示词。执行无需读取上下文；修改参数或扩风格库时可读源码。用法见文件头注释。

### references/
按需加载，不预先读入：

- `references/style-library.md` —— 室内设计风格库：各风格特征、色彩/材质/灯光关键词。风格定位与风格改造时读。
- `references/prompt-library.md` —— AI 生图提示词规范：模板结构、场景词、负面词、参数。生成与修改效果图时读。
- `references/kujiale.md` —— 酷家乐建模与改图操作要点。用户指定酷家乐时读。
- `references/3d-modeling.md` —— SketchUp / 3ds Max / Blender 室内建模要点。用户指定这些软件时读。
