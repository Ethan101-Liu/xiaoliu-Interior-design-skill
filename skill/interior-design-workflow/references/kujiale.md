# 酷家乐建模与改图操作要点

用途：用户指定酷家乐时，按本文件输出可执行的建模与改图步骤。所有指令含工具名、菜单路径、快捷键与参数。

## 新建方案与导入户型

1. 云设计平台 →「开始设计」→ 选择「导入户型图」或使用模板户型
2. 导入 CAD/图片户型：上传户型图 → 自动识别墙体 → 手动校正墙线偏移
3. 检查层高与单位：默认 2.8m 层高，导入后先核对比例尺
4. 快捷键：`B` 画墙 / `D` 测量 / `W` 门窗 / `F` 地板 / `C` 天花

## 户型绘制（建墙）

1. 画墙：快捷键 `B` → 指定墙厚（承重墙 240mm，隔墙 120mm）→ 沿轴线绘制
2. 改墙：选中墙体 → 属性面板改厚度/高度/材质；「拆分」用于局部改墙
3. 门窗：快捷键 `W` → 拖入门窗模型 → 属性面板设定宽高、离地高度、开启方向
4. 检查：用「净高检测」「面积统计」核对空间尺寸

## 硬装施工

1. 吊顶：选中顶面 →「吊顶设计」→ 绘制石膏线、灯带槽（留 8-10cm 反光灯槽）；跌级吊顶设定下吊高度
2. 地面：「地面设计」→ 选瓷砖/木地板规格（600×1200、750×1500）→ 设定铺贴方式（工字/人字/通铺）→ 波打线宽度
3. 墙面：背景墙用「墙面造型」→ 护墙板/格栅板拼装，设定板宽与分隔；乳胶漆直接选色
4. 定制柜：进入「全屋定制」→ 选衣柜/橱柜/榻榻米模块 → 拖入后调尺寸（宽度按 50mm 模数）→ 板材、柜门（平板门/格栅门）、把手（无把手设计选反弹器）

## 家具布置

1. 素材库检索（按风格/尺寸筛选）→ 拖入场景
2. 对齐与摆放：「摆放」吸附地面，「阵列复制」用于餐椅/筒灯
3. 尺寸复核：用 `D` 测量工具核对过道宽度（≥900mm）、床两侧通道（≥600mm）

## 材质替换

1. 选中物体 →「材质替换」→ 系统材质库或「上传贴图」（自备纹理需 1:1 无缝图）
2. 全局替换：场景中同类材质可一键全选替换
3. 注意：木饰面纹理方向可在材质面板调整旋转/缩放

## 灯光布置

1. 入口：「灯光」→ 自动灯光模板（白昼/夜晚）快速打底
2. 手动布光：筒灯（间距 1-1.2m，功率 7-9W，色温 3000-4000K）、射灯（洗墙角度 30°）、灯带（亮度 200-300lm/m）
3. 主灯：吊灯/吸顶灯拖入后设「发光」属性，避免渲染发黑

## 渲染与导出

1. 渲染设置：分辨率（≥2K）、灯光模板（写实）、外景与阳光参数
2. 「渲染」→ 普通图/全景图；全景图用于 VR 看房
3. 导出：效果图 PNG、施工图（平面图/立面图/水电图）导出 DWG 或 PDF

## 常见改图操作

| 改什么 | 操作 |
|---|---|
| 改墙位置 | 选中墙 → 拖动端点；需连带改天花/地面时用「拆改」重铺 |
| 换家具 | 选中 → 删除 → 从素材库拖入新模型；同风格系列可整组替换 |
| 换材质 | 选中 → 材质替换 → 选择/上传新材质 |
| 调整布局 | 框选多个家具 → 整体移动；「锁定」固定已完成区域防误动 |
| 户型改造 | 工具「拆墙/砌墙」→ 需在「承重墙标记」开启状态下避开承重结构 |

## 输出规则

给用户的指令必须：写明工具入口（菜单/快捷键）、关键参数（尺寸、间距、色温、功率）、可校验的结果（净高、过道宽度、柜体模数）。
